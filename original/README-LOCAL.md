# اجرای محلی فروشگاه «الکتریکی و قطعات الکترونیک یاسایی تهران» روی سیستم خودت

> برند رسمی: **الکتریکی و قطعات الکترونیک یاسایی تهران** (نارمک، هفت‌حوض) · تاریخ رسمی این نسخه:
> **شهریور ۱۴۰۵ هجری شمسی** (1405 SH) · نسخهٔ رسمی `v1.0.0` · سایت زنده: https://yassaei-electronics.onrender.com

## روش ۱ — نسخهٔ کامل با پنل مدیر (نیاز به Node.js)
1. برنامهٔ Node.js نسخهٔ LTS را نصب کن: https://nodejs.org (در ایران هم دانلود می‌شود؛ نصب Next/Next را بزن تا تمام شود).
2. همین پوشهٔ پروژه را هر جا خواستی کپی کن (مثلاً `C:\yassaei-electronics` یا `~/yassaei-electronics`).
3. یک Terminal / CMD باز کن و برو داخل پوشه:
   - ویندوز: `cd C:\yassaei-electronics`
   - مک/لینوکس: `cd ~/yassaei-electronics`
4. دستور بزن:
   node server/main.mjs
5. مرورگر (کروم) را باز کن و برو به:  http://localhost:3000
6. ورود مدیر: `admin` رمز `Yassaei@1404` — کارمند: `staff` / `Staff@1404` — کاربران نمونه: `maryam|reza|sina` رمز `Demo@1404`

نکته‌ها:
- **زمان اجرا** هیچ وابستگی خارجی ندارد (برای اجرای سرور، `npm install` لازم نیست). فقط برای `npm run build` و تست‌ها (`npm run verify`) دو بستهٔ توسعه لازم است: `npm install` یک‌بار.
- داده‌ها در `data/db.json` ذخیره می‌شوند؛ از پنل مدیر → بینش‌ها → پشتیبان‌گیری هم می‌توانی بکاپ بگیری.
- برای بستن سرور: Ctrl+C در همان ترمینال.
- اگر پورت 3000 اشغال بود: `PORT=3005 node server/main.mjs` و بعد http://localhost:3005

## روش ۲ — نسخهٔ تک‌فایلی آفلاین (بدون نصب هیچ چیز)
فایل `yassaei-offline.html` را دوبار کلیک کن تا در کروم باز شود.
- کل فروشگاه، سبد، سفارش، حساب کاربری، تیکت و حتی پنل مدیر به‌صورت محلی داخل مرورگر کار می‌کند.
- داده‌ها در حافظهٔ مرورگر (localStorage) همان سیستم ذخیره می‌شوند: کلید `ys_stand_db_v2` (نشست: `ys_stand_session`).
- برای برگرداندن داده‌ها به حالت اول: از منوی توسعه‌دهنده → Application → Local Storage → حذف کلید `ys_stand_db_v2` و رفرش.
- بازسازی نسخهٔ تک‌فایلی پس از هر تغییر: `node tools/standalone-build.mjs` (بذر پاک‌سازی‌شده: بدون رمز/توکن/دادهٔ مشتری).
- محدودیت‌های نسخهٔ تک‌فایلی: جست‌وجوی تصویر آنلاین و دریافت تصویر خودکار کالا (که به اینترنت/سرویس خارجی نیاز دارد) غیرفعال است؛ خروجی اکسل پنل هم ساده‌شده است.

## محافظت در برابر Inspect و برداشت کد
- پیش‌فرض **روشن** است (کلیک راست، میان‌برهای DevTools، هشدار کنسول و جلوگیری از کشیدن تصاویر) و
  تایپ/فرم/جست‌وجو/لمس موبایل هیچ تغییری نمی‌کند.
- خاموش یا روشن‌کردن: پنل مدیر → تنظیمات → تب **امنیت و محافظت از کد** (`#/admin/settings/security`).

## رمزها را عوض کن
بعد از اولین ورود، از پنل مدیر → کاربران، رمز عبور را تغییر بده.
