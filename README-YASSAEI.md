## گردش کار تغییر و دیپلوی (مثل پروژه ۱)
1. تغییر در کد/داده → تست محلی: `BM_TG=off BM_QUEUE=off PORT=3000 node server/main.mjs`
2. **بررسی یک‌دستوری:** `npm run verify` (سرور آزمایشی با پوشهٔ دادهٔ جدا بالا می‌آید،
   همهٔ سوئیت‌های تست (امروز ۲۳ سوئیت، شامل `anti-inspect`) + جاروب رازها اجرا می‌شود و دادهٔ واقعی
   `data/db.json` دست‌نخورده می‌ماند)
3. برای نسخهٔ جدید: `npm run bump` — تگ BUILD را هم‌زمان در `public/js/state.mjs`، `public/sw.js`،
   `server/lib/util.mjs`، باندل و `yassaei-offline.html` جلو می‌برد؛ بعد `node tools/gen-sw-precache.mjs` (کش سرویس‌ورکر)
4. commit + push به main. **push به‌تنهایی دیپلوی نمی‌کند** (autoDeploy روی کاغذ yes است ولی عمل نمی‌کند):
   `POST https://api.render.com/v1/services/srv-dahcik6k1f9s73fajff0/deploys` با هدر `Authorization: Bearer <کلید Render>` و بدنهٔ `{"clearCache":"do_not_clear"}`
5. بررسی: `GET /api/system/status` → فیلد build باید تگ جدید باشد.

## بات تلگرام
- توکن را **در متغیر محیطی `BM_TG_TOKEN`** بگذارید (اولویت دارد بر پنل) یا در تنظیمات → تلگرام پنل.
  اسکریپت‌های کمکی (`seed_channel.mjs`، `setup_channel.mjs`، `fix_image_fetch.mjs`، `react_existing.mjs`)
  هم توکن را از همین متغیر یا پنل می‌خوانند و هیچ رمزی در کد نیست.
- اگر توکن لو رفت (مثلاً در گیت دیده شد): BotFather → /revoke و توکن جدید را در ENV بگذارید.
  برای بررسی پاک‌بودن ریپو: `node tools/secret-scan.mjs`

## خواب/بیداری سرویس free
- سرویس free بعد از بی‌کاری می‌خوابد؛ اولین درخواست بیدارش می‌کند (چند ثانیه تأخیر).
- برای بیداری دستی: یک‌بار `https://yassaei-electronics.onrender.com/healthz` را در مرورگر باز کنید،
  یا UptimeRobot را روی همان آدرس هر ۵ دقیقه بگذارید. (نسخهٔ تک‌فایلی `yassaei-offline.html` هم بدون سرور کار می‌کند.)

## امنیت (یادآور دائم)
- خروجی `node tools/secret-scan.mjs` باید «۰ خطا» بدهد (هشدارهای data/ مربوط به توکن زندهٔ دیتابیس است).
- محافظت سمت کاربر (`settings.security.antiInspectEnabled`، پیش‌فرض روشن): کلیک راست، میان‌برهای
  DevTools، هشدار کنسول و ضدکشیدن تصاویر — خاموش‌کردن از پنل مدیر → تنظیمات → `#/admin/settings/security`.
- توکن‌های گیت/Render/بات که در چت رد و بدل شده‌اند را پس از تثبیت سایت **revoke** کنید و از پنل/ENV جدید بگذارید.
- رمز ادمین را در اولین ورود عوض کنید؛ staf اضافه کنید به‌جای اشتراک رمز owner.
